# Mosety Creations Showcase

Public GitHub Pages showcase for **Mosety Creations**. It presents the customer-facing design, real project photography, service range, and an overview of the connected Business Studio.

## Live business website

https://mosetycreations.pythonanywhere.com/

## What this repository is

This is a **static showcase only**. The real application is a Django business operating system hosted separately and includes customer management, quotations, projects, invoices, payments, receipts, document PDFs, media management and website administration.

No production database, credentials, customer records, secret keys, or owner login functionality are stored in this public repository.

## GitHub Pages

After pushing the repository, open **Settings -> Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The Pages URL will be:

`https://movirtualstudios.github.io/mosety-creations-showcase/`

## Technology represented

- Django (production application)
- Bootstrap responsive interface
- Django templates
- Vanilla JavaScript
- PWA Business Studio
- Professional PDF generation
- Responsive phone and desktop administration

## Photography

The project photography in this showcase is Mosety Creations work supplied for use in the business website.
